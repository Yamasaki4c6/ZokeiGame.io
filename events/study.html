HOUDINI + GITHUB

Houdini+GitHub導入会

日時7月28日(火)13:00〜19:30
場所3-205号室(オンライン参加可能)
内容インストール → チュートリアル → GitHubにTIL

Houdiniに興味はあるけれど何から始めたらいいか分からない、一人だと続けられるか不安。そんな方に向けて、足並みを揃えて一歩目を踏み出す勉強会です。Apprenticeのインストールとアトリビュートの解説を通して触れたあと、GitHubにリポジトリを作成してTIL(今日学んだこと)を付けるまでを手引きしました。
